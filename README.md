# 🏠 Room & PG Finder

A MERN Stack based web application that helps users find suitable rooms and PG accommodations according to their location, room type, and budget.

## 🚀 Features

- 🔐 User Login & Registration
- 🏠 Browse available Rooms & PGs
- 📍 Filter rooms by location
- 🛏️ Filter by room type
- 💰 Filter by budget
- 📸 Room images
- 📋 View complete room details
- 📱 Contact owner through WhatsApp
- 🗄️ MongoDB database integration

## 🛠️ Technologies Used

### Frontend
- React.js
- Vite
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

### Authentication
- bcryptjs
- JSON Web Token (JWT)
